# PO Web — نظام إدارة المشتريات والعقود (الإصدار 10)

شركة الهضب للتجارة والمقاولات — يعمل على خادم داخلي واحد، ويصل إليه الفريق من المتصفح.

## البدء السريع (على الجهاز الرئيسي)

```
pip install -r requirements.txt
copy config.ini.example config.ini        (ثم عدّل المسارات داخله)
python migrate.py                         (يجهّز/يحدّث القاعدة - آمن للتكرار)
python tools\add_user.py                  (لكل عضو في الفريق)
python tools\setup_check.py               (فحص الجاهزية)
python serve.py                           (التشغيل)
```

التفاصيل الكاملة: `docs\دليل_التشغيل_على_الشبكة.md`

## التشغيل من قرص خارجي (بدون تثبيت دائم)
استخدم `config.ini.portable.example` (مسارات نسبية، لا تتأثر بتغيّر حرف القرص)، و`python tools\find_db.py E:\` لمعرفة مكان ملف القاعدة.

## هيكل المشروع
```
app.py              بناء التطبيق (إعدادات، سجلات، صفحات الأخطاء، رؤوس الأمان)
serve.py            التشغيل الإنتاجي (Waitress)
config.py           كل الإعدادات من مكان واحد (config.ini)
archive.py          محرك الأرشفة: المجلدات، حفظ المستندات وفهرستها، تقديم الملفات
db.py / auth.py     قاعدة البيانات / تسجيل الدخول
order_services.py   دوال مشتركة للمشتريات      finance.py   حسابات المستخلص
projects.py         قائمة المشاريع الموحّدة       textnorm.py  توحيد الكتابة العربية (بحث/أصناف/مشاريع)
items_service.py    الأصناف من أوامر الشراء       analytics_service.py + excel_dashboard.py   اللوحة وتقريرها
quote2po.py         قراءة عروض الأسعار          arabic_numbers.py   المبلغ كتابةً
routes\             المسارات: orders, suppliers, subcontractors, contracts,
                    certificates, documents, analytics, auth_routes, system
migrations\         ترحيلات القاعدة مرقّمة + مشغّل واحد  (python migrate.py)
templates\ static\  الواجهة
tools\              add_user, setup_check, check_storage, uat_report
deploy\             سكربتات التشغيل والجدار الناري والنسخ الاحتياطي
```

## هيكل الأرشيف (يُنشأ تلقائيًا)
```
<مجلد الأرشيف>\
  الموردين\<المورد>\<المشروع>\<رقم أمر الشراء>\      ← أمر الشراء، عرض السعر، سند الاستلام، الفاتورة، سند السداد، مرفقات
  المقاولين\<المقاول>\<المشروع>\<الموقع>\مستخلص <رقم>\ ← المستخلص المعتمد، سند الصرف، مرفقات ثبوتية
```
- المجلد يُنشأ لحظة إنشاء الأمر أو المستخلص، ويُحفظ مساره في القاعدة (تعديل اسم المورد لاحقًا لا يفقد الملفات).
- لا يُكتب فوق أي ملف ولا يُحذف: الاستبدال يُبقي النسخة السابقة (تظهر في «النسخ السابقة»).
- ترقيم المستخلصات مستقل لكل موقع (1، 2، 3 …).

## المستخدمون والصلاحيات
- تسجيل مستخدم جديد من صفحة الدخول ← يظهر عند المدير في **الإعدادات ← المستخدمون** ← يوافق ويحدد الدور.
- الأدوار والصلاحيات تُعدَّل من **الإعدادات ← الأدوار والصلاحيات**. كل عملية تُسجَّل في **سجل التدقيق**.
- قبل أول تشغيل بعد التحديث: `python migrate.py` (يأخذ نسخة احتياطية من القاعدة تلقائيًا).

## الأمان
- لا يعمل وضع التطوير (debug) إطلاقًا؛ الأخطاء تُسجَّل في `logs\error.log` وتظهر للمستخدم صفحة عادية.
- إيقاف الدخول 10 دقائق بعد 5 محاولات خاطئة، ومفتاح الجلسات ثابت (لا يُخرج الفريق عند إعادة التشغيل).
- كل مسار ملف يُتحقق أنه داخل مجلد الأرشيف.

## السجلات
`logs\access.log` (كل طلب وزمنه) · `logs\error.log` · `python tools\uat_report.py` لتلخيصها.
