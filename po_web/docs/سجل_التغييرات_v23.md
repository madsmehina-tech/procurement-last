# سجل التغييرات — v23.0 (مقارنة عروض الأسعار)

وحدة جديدة تحت قسم **المشتريات**: «مقارنة عروض الأسعار» — قبل أمر الشراء أو العقد. تعمل مع المواد والمقاولين والخدمات.

## خطوات العمل (5)
1. **بيانات المقارنة:** الاسم، المشروع، الموقع (من القوائم الموحدة)، النوع، وصف.
2. **رفع العروض:** PDF / Word / Excel / صور، أو لصق جدول من Excel، مع قالب Excel جاهز. القراءة بمحرك `quote2po` الموجود (نفسه شاشة أمر الشراء). عند فشل القراءة المباشرة **وبوجود مفتاح API** في `config.ini` تُجرَّب قراءة الذكاء الاصطناعي (اختيارية).
3. **مراجعة القراءة:** الأسطر المقروءة قابلة للتعديل بجانب الملف الأصلي، مع مجموع حي ومقارنته بإجمالي العرض المكتوب لكشف أخطاء القراءة.
4. **مطابقة البنود:** يقترح النظام تجميع الصيغ المختلفة (الاسم والمقاس والوحدة)؛ **المطابقات الضعيفة تُعلَّم «راجع»** وتؤكدها أنت. **ما تؤكده يتذكره النظام** (`ItemAliases`) فتبدأ المقارنة التالية أذكى.
5. **المقارنة والقرار.**

## جدول المقارنة (أساس واحد عادل لكل العروض)
- الأسعار **قبل الضريبة** (العرض «شامل الضريبة» يُقسم على 1.15).
- **الكمية المطلوبة** لكل بند موحّد (الأكثر تكرارًا بين العروض أو تكتبها)؛ اختلاف كمية أو وحدة العرض يُنبَّه عليه.
- **البند الناقص** بلون واضح وعبارة «البند غير موجود في عرض المورد».
- **الإجمالي المعدّل:** يستكمل الناقص بمتوسط أسعار العروض الأخرى حتى لا يفوز عرض بحذف بنود.
- **سجل الأسعار** لكل بند من أوامر الشراء (آخر سعر، المتوسط، الأعلى، الأقل، عدد المرات) + أسعار عروض سابقة كمصدر منفصل. (العقود بلا بنود فلا تدخل.)
- **ألوان الأسعار:** 🟢 أقل من المتوسط بأكثر من 5% · 🟡 من −5% إلى +10% · 🔴 أعلى من +10% · 🟣 منخفض جدًا (أقل من −30%: غالبًا اختلاف مواصفات).
- **لوحة القرار:** أفضل سعر · أقل إجمالي · أكثر البنود اكتمالًا · **أفضل قيمة** = أقل إجمالي معدّل بين العروض التي تغطي 80% أو أكثر.

## الترسية
- «اعتماد العرض الفائز» بعد تأكيد المطابقة. **يُطلب سبب مكتوب** إن لم يكن الفائز الأرخص ولا «أفضل قيمة»، أو كان ناقصًا (<80%)، أو فيه أسعار منخفضة جدًا.
- يُحفظ الفائز والوفر (مقابل متوسط باقي العروض ومقابل أعلى عرض).
- **إنشاء أمر شراء** جاهز بالمورد والمشروع والبنود الموحّدة والكمية المطلوبة والأسعار قبل الضريبة (ويُرفق عرض السعر الأصلي)، أو **إنشاء عقد** (نافذة العقد معبأة) للمقاولين؛ وحفظ الأمر يربطه بالمقارنة تلقائيًا.
- لا تُحذف مقارنة تمت ترسيتها، ولا تُلغى ترسية رُبطت بأمر.

## التقارير والأرشيف والإحصائيات
- طباعة A4 أفقي وPDF وExcel (4 أوراق كلها جداول Excel حقيقية: المقارنة، العروض، مطابقة البنود، الأسعار التاريخية).
- **الأرشيف:** `المشتريات / مقارنات الأسعار / <المشروع> / <المقارنة> / {العروض الأصلية، تقرير المقارنة، العرض الفائز}`؛ تُحفظ العروض الأصلية، وعند الترسية تقرير المقارنة PDF ونسخة العرض الفائز.
- كل المقارنات محفوظة؛ صفحة القائمة تعرض عدد المقارنات والترسيات ووفر التكاليف والمورد الأكثر فوزًا ونسبة فوز كل طرف.

## قاعدة البيانات
- الترحيل **m024**: `Comparisons` · `ComparisonItems` · `Quotes` · `QuoteLines` · `ItemAliases`. لا يمس بيانات موجودة. صلاحيات جديدة: `compare.view` · `compare.edit` · `compare.award`.
