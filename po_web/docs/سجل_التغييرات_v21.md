# سجل التغييرات — v21.0

## أرشفة الدفعات والحركات المالية (جديد)
الهيكل (يكمّل أرشيف المقاول الحالي):
```
إدارة مقاولي الباطن / <المقاول> / الدفعات والحركات المالية / <السنة> /
      دفعة رقم N - <التاريخ>                   ← تحويل دورة صرف أو دفعة مباشرة منفّذة
      <التصنيف> - <التاريخ> - <الوصف>          ← مواد على المقاول، رد خصم، رد ضريبة، تسوية
      دفعة مسجلة (لم تُنفَّذ) - <التاريخ> - … ← تنتقل إلى فولدر الدفعة عند «تم التحويل»
```
- **رقم الدفعة مخزَّن** لكل مقاول عند التنفيذ ولا يتغير (تحويل دورة الصرف = دفعة واحدة)، فيتفق فولدرها وأمر الصرف وكشف الحساب.
- **تحويل الدورة:** الملفات (أمر الصرف الموقّع + صورة تحويل البنك، ملف أو أكثر) تُحفظ **مرة في فولدر الدفعة، ونسخة منها في فولدر كل مستخلص دُفع بها كـ «سند الصرف»** (الورقة الخامسة من أوراق المعاملة). يمكن رفعها عند «تم التحويل» أو **لاحقًا** من «رفع ملفات التحويل».
- **الحركات اليدوية** (دائن/مدين، دفعة مباشرة): رفع ملف أو أكثر (سند/إيصال، فاتورة، مرفق) عند الإضافة أو لاحقًا من الصف.
- صفحة جديدة **«أرشيف الدفعات والحركات المالية»** (من صفحة الأرشيف ومن قسم الدفعات في صفحة المقاول): كل دفعة وحركة منفّذة بنوعها ورقمها وبيانها ومبلغها وفولدرها وملفاتها، مع فلتر المقاول والسنة.
- أمر الصرف **لا يُحفظ تلقائيًا** (بقرارك): يُطبع ويُوقَّع ويُمسح ضوئيًا ويُرفع مع صورة التحويل.
- كشف الحساب لا يُؤرشف تلقائيًا (يُطبع عند الحاجة).

## إصلاح
- **معاملة التحويل كانت لا تُحسب الورقة الخامسة:** كانت تُخزَّن بنوع «معاملة المستخلص» بينما إقفال المعاملة يبحث عن «سند الصرف». صار النوع «سند الصرف» (والملفات القديمة بالاسم القديم تتحول إليه في الترحيل).
- «سند الصرف» يقبل أكثر من ملف (تحويلان على مستخلص واحد).
