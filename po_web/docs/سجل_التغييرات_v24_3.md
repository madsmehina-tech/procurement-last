# سجل التغييرات — v24.3 (تقوية قبل التشغيل الفعلي)

ثلاث إصلاحات من مراجعة الجاهزية، بلا مزايا جديدة وبلا ترحيل:

1. **كاتب واحد في كل مرة:** كل طلب يغيّر بيانات (حفظ/تعديل/حذف) ينتظر دوره؛ الصفحات التي تقرأ فقط لا تنتظر. يمنع تكرار أرقام أوامر الشراء والدورات والدفعات والعقود لو حفظ مستخدمان في اللحظة نفسها (جُرّب بـ12 حفظًا متزامنًا: 12 رقمًا مختلفًا).
2. **صفحة المقاول أسرع بكثير مع كثرة المستخلصات:** كانت تسأل القاعدة مرة لكل مستخلص (407 استعلامًا مع 380 مستخلصًا)، الآن 24 استعلامًا ثابتة. على Access كل استعلام يفتح اتصالًا جديدًا فالفرق يصل لثوانٍ كثيرة.
3. **تحويل PDF بـWord لا يعلّق النظام:** مهلة 90 ثانية، ورسالة واضحة عند وجود نافذة عالقة، ولا يحجز قفل الكتابة أثناء إنشاء الملفات.
4. **نسخ احتياطي تلقائي أثناء التشغيل:** نسخة من القاعدة كل 12 ساعة (قابلة للتعديل) في مجلد النسخ **وفي مكان ثانٍ** إن ضبطت `backup_extra_dir`. تُؤخذ والكتابة موقوفة لحظات فلا تلتقط ملفًا نصف مكتوب. التنظيف لكل نوع على حدة (لا تُمحى نسخ ما قبل الترحيل). حالتها في `/health` وعند تشغيل الخادم.

## إعداد مطلوب (config.ini، قسم [storage])
```
backup_auto_hours = 12
backup_extra_dir  = D:\PO_Backup_Second        ; قرص/جهاز/مجلد OneDrive غير قرص القاعدة
```
