# v27.0 — تنفيذ التصاميم المعتمدة (المرحلة 1)

## الأساس
- **الخط Cairo** يُنسخ مع النظام (`static/fonts/`، رخصة OFL) فلا يحتاج إنترنت، ويظهر في كل الصفحات.
- **الجوال:** شريط تنقل سفلي (الرئيسية · المقاولون · الصرف · الأوامر · المزيد)، وكل الجداول البسيطة تظهر **بطاقات** بدل الأعمدة (اسم العمود يظهر بجانب كل قيمة تلقائياً)، وتبويبات تنزلق أفقياً، وأرقام البطاقات أصغر، وأزرار «إجراءات سريعة» في الرئيسية، وزر «تصفية وبحث» يطوي الفلاتر.

## شاشة المستخلصات (بالتصميم المعتمد، بكل فلاترها)
- أربع بطاقات: إجمالي المستخلصات · المصروف · المتبقي · مُدخَل ولم يدخل دورة.
- **أزرار الحالة** (الكل · مُدخَل · ضمن دورة · مصروف · مرفوض) لكل منها عددها ومبلغها؛ ويبقى عدد كل حالة ثابتاً عند اختيار واحدة (كان يصير صفراً).
- **كل الفلاتر القديمة باقية:** بحث نصي، المقاول، المشروع، من تاريخ، إلى تاريخ، الحالة.
- الجدول: شريط تقدم المصروف، والخصومات تحت القيمة، ورقم الدورة تحت الحالة، والصف كله قابل للنقر. زر «+ مستخلص جديد» وتصدير Excel كما كانا.
