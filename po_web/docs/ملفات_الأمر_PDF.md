# ملفات أمر الشراء في الأرشيف

كل أمر شراء يُحفظ **نفسه** على القرص، لا عرض سعره فقط:

```
الموردين \ <المورد> \ <المشروع> \ <رقم الأمر> \
    أمر الشراء \       PO-xxxx.pdf   (الأمر كما يُطبع)      PO-xxxx.json  (نسخة بياناته)      + النسخة الموقعة إن رُفعت
    المرفقات \         عرض السعر، سند الاستلام، الفاتورة، سند السداد، المرفقات الإضافية
    النسخ السابقة \    PO-xxxx_v1.pdf + PO-xxxx_v1.json ...   (كل نسخة استُبدلت بتعديل)
```

- يُنشأ الملفان عند «حفظ أمر الشراء»، ويُحدَّثان عند «حفظ التعديل». قبل أي تعديل تُحفظ النسخة الحالية في «النسخ السابقة».
- إن لم يتوفر PDF لأي سبب فالأمر ونسخة بياناته محفوظان، وتظهر في صفحة الأمر رسالة بالسبب وزر **إنشاء PDF**.

## كيف يُصنع الـPDF
بمتصفح **Microsoft Edge أو Google Chrome** الموجود على الجهاز يعمل دون نافذة، فيطبع العربية كما تراها على الشاشة. لا يُثبَّت شيء. إن لم يُوجد تلقائيًا ضع مساره في `config.ini`:
```
[pdf]
browser_path = C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```
التحقق: `python tools\setup_check.py` يعرض سطر «إنشاء PDF لأمر الشراء: جاهز».

## لأوامرك المحفوظة قبل هذا الإصدار
1. `python migrate.py` ينقل ملفاتها القديمة إلى «المرفقات» و«أمر الشراء» (بنسخ ثم تحقق ثم حذف الأصل).
2. `python tools\make_po_pdfs.py` يكتب PDF ونسخة بيانات لكل أمر ليس لديه (أو زر «إنشاء PDF» في صفحة كل أمر).

## فحص الأرشيف
`python tools\check_archive.py` أو **الإعدادات ← صحة الأرشيف**: يقرأ فقط ولا يغيّر شيئًا. يُظهر (1) سجلات تشير لملف غير موجود، (2) ملفات على القرص لا تعرفها القاعدة، (3) أوامر بلا مجلد أو PDF. شغّله بعد نقل الأرشيف أو استعادة نسخة احتياطية.
