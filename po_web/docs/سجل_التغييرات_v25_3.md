# التغييرات في النسخة 25.3 (الواجهة وسهولة الاستخدام)

1. **الجوال:** الصفحات تتكيف مع الشاشة الصغيرة؛ القائمة الجانبية تُفتح بزر «☰ القائمة»، والجداول تنزلق أفقياً، والأزرار والحقول أكبر للمس.
2. **الخطوط:** لا يُحمَّل أي شيء من الإنترنت (خطوط جوجل أُزيلت). يستخدم النظام خطوط ويندوز (Segoe UI / Tahoma). النتيجة: صفحات أسرع وتعمل بلا إنترنت.
3. **الرسائل الملوّنة:** أخضر = تمّ، أحمر = ممنوع أو خطأ، أصفر = تنبيه. الأحمر يُقرأ فوراً لقارئات الشاشة (role=alert).
4. **«ما يحتاج انتباهك»:** لوحة في الصفحة الرئيسية: فواتير متأخرة، فواتير تستحق خلال 7 أيام، استلام جزئي، مستخلصات لم تدخل دورة، مستخدمون ينتظرون الموافقة، تحذيرات النسخ الاحتياطي. كل بند رابط، ويظهر فقط لمن يملك صلاحية الصفحة.
5. **منع الضغط المزدوج:** بعد الضغط على «حفظ» تُعطَّل الأزرار 8 ثوانٍ كي لا يُرسَل النموذج مرتين.
6. **الصفوف القابلة للضغط** تعمل أيضاً بلوحة المفاتيح (Tab ثم Enter).
7. **سهولة الوصول:** رابط «تخطَّ إلى المحتوى»، إطار تركيز واضح، علامة الصفحة الحالية في القائمة، عنوان تبويب خاص بكل صفحة.
8. **الطباعة:** إخفاء الأزرار والرسائل، وتكرار رأس الجدول، ومنع انقسام الصف بين صفحتين.

الاختبارات: 164 ناجحاً.
