# قراءة عروض الأسعار المصوّرة والممسوحة (OCR)

**متى تحتاجه؟** حين يكون عرض السعر **صورة** (JPG/PNG)، أو PDF **ممسوحًا** ضوئيًا، أو PDF **نصّه تالف** (يظهر اسم المورد حروفًا غريبة أو مفصولة). عندها يقرأ النظام الصورة بالتعرف الضوئي ويرتّب الأصناف بالطريقة نفسها.
**هو اختياري:** بدونه تعمل كل عروض PDF/Word/Excel العادية، وتبقى الصور تُدخل أصنافها يدويًا.

## التثبيت (على الجهاز الرئيسي فقط، مرة واحدة)
1. ابحث عن **Tesseract UB Mannheim** (صفحة `github.com/UB-Mannheim/tesseract/wiki`) وحمّل نسخة ويندوز 64-bit.
2. شغّل المثبّت. في شاشة **Additional language data** علّم **Arabic** (والإنجليزية موجودة).
3. اترك المسار الافتراضي `C:\Program Files\Tesseract-OCR`.
4. تحقق (موجه الأوامر):
   ```
   "C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs
   ```
   يجب أن تظهر `ara` و`eng`.
5. ثبّت مكتبتي بايثون: `pip install pytesseract pillow`
6. في `config.ini` أضف (إن لم يُكتشف Tesseract تلقائيًا):
   ```
   [ocr]
   tesseract_path = C:\Program Files\Tesseract-OCR\tesseract.exe
   language = ara+eng
   mode = auto
   ```
7. تأكد: `python tools\setup_check.py` يعرض سطر «قراءة الصور والملفات الممسوحة (OCR): جاهزة».

## كيف تستخدمه
في «إنشاء أمر شراء» اختر ملف العرض (صورة أو PDF) ثم «قراءة تلقائية للأصناف». تظهر في أعلى الصفحة **تحذيرات المراجعة**، وفيها تنبيه خاص عند القراءة بالـOCR. **راجع كل رقم واسم** ثم علّم مربع «راجعت…» لتتمكن من الحفظ.

## ما تتوقعه
- جودة القراءة تعتمد على وضوح الصورة: صورة مستقيمة وواضحة بدقة جيدة تُقرأ أفضل بكثير من صورة جوال مائلة أو معتمة.
- الأرقام والأسماء قد يخطئ فيها OCR أحيانًا، ولهذا لا يُحفظ أي أمر مقروء قبل تأكيدك.
- اسم المورد يُطابَق تلقائيًا مع الموردين المسجّلين ويُصحَّح إلى الاسم المسجّل إن كان شبيهًا به.
