# v27.3 — إصلاحات من فحص خارجي (أمان وسلامة)

1. **ثغرة الصفوف القابلة للنقر:** رقم أمر الشراء (أو مفتاح الصنف) كان يدخل داخل كود جافاسكربت في 13 صفحة؛ قيمة تحتوي على علامة اقتباس كانت تستطيع تشغيل كود. صار العنوان بيانات نصية (`data-href`) لا كوداً، ولا يتبع النظام إلا العناوين الداخلية التي تبدأ بـ `/`.
2. **رقم أمر الشراء:** يقبل الحروف والأرقام و - _ . / والمسافة فقط (حتى 40 خانة).
3. **المعاملات:** إن فشل فتح اتصال المعاملة لسبب غير «سائق بلا معاملات» (ملف مقفل، انقطاع شبكة) يتوقف الحفظ بدل أن تُنفَّذ خطواته منفصلة.
4. **المكتبات:** Flask 3.1.3 وWerkzeug 3.1.9 (فحص pip-audit: لا ثغرات معروفة؛ كان 8 معرفات في الإصدارين القديمين).
5. **سهولة الوصول:** كل تسمية (label) بلا ربط تُربط تلقائياً بحقلها.
**مهم عند التركيب:** شغّل `pip install -r requirements.txt` ثم أعد تشغيل النظام.
