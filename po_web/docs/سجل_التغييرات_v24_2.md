# سجل التغييرات — v24.2

## نقص مكتبة على جهاز لا يوقف النظام
اكتُشف عند نقل القرص من لابتوب المكتب لابتوب البيت: مكتبات بايثون تُثبَّت **على كل جهاز لوحده**، فغياب `python-docx` على الجهاز الثاني أوقف تشغيل النظام كله.
- الآن النظام **يعمل** حتى لو المكتبة ناقصة؛ وصفحات العقود فقط (توليد، رفع قالب، تجربة قالب، القوالب الأساسية) تقول: «مكتبة python-docx غير مثبّتة على هذا الجهاز: python -m pip install -r requirements.txt».
- **أي جهاز جديد تشغّل عليه النظام:** مرة واحدة `cd /d E:\PO_System\po_web` ثم `python -m pip install -r requirements.txt`.
