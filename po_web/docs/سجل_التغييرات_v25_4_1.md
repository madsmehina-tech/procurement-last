# v25.4.1 — إصلاح نافذة تأكيد الإقفال (للمرة الثانية)

**العيب:** نص التأكيد كان يحوي علامات اقتباس مزدوجة داخل خاصية HTML مفتوحة بعلامات مزدوجة، فكان المتصفح يقطع الخاصية ولا تظهر نافذة التأكيد، ويُنفَّذ الإقفال مباشرة. (ظهر في اختبارك الميداني على v25.4.)
**الإصلاح:** الخاصية صارت بعلامات مفردة (`onsubmit='return confirm(...)'`)، وهي آمنة لأن النص المُمرَّر يهرّب العلامة المفردة.
**لماذا فات اختباري السابق:** كان يستخرج النص بتعبير نمطي متساهل. صار الآن يقرأ الصفحة بمحلّل HTML حقيقي كما يفعل المتصفح، ويفشل على الكود القديم.
**فحص جديد:** كل الصفحات الرئيسية تُحلَّل وتُرفض أي خاصية HTML مقطوعة.
الاختبارات: 177.
