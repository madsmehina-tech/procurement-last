# سجل التغييرات — v23.1

## مقارنة عروض الأسعار: اسم المورد المقروء من الملف
اكتُشفت في أول تجربة على عروض PDF حقيقية:
- **القراءة جابت أسماء غلط:** سطر «Customer Name : Al-Hadab Co. …» (شركتنا نحن) وعنوان إيميل بدل اسم المورد.
- **العرض الثالث رُفض** برسالة «حدّد المورد…» بلا مكان لتحديده.

**الإصلاح:**
- الاسم المقروء من الملف أصبح **اقتراحًا فقط**: يُهمل إن كان إيميلًا أو رابطًا أو اسم شركتنا أو سطرًا من نوع «Customer / Quotation / Tel …» أو أرقامًا، ويُطابَق مع الموردين المسجّلين فيأخذ الاسم المسجّل إن كان مشابهًا.
- إن لم يُعرف اسم يُحفظ العرض **باسم مؤقت «عرض بلا اسم N»** بدل الرفض، ويظهر عليه تنبيه.
- **صفحة مراجعة العرض فيها «الطرف»** (مورد/مقاول + الاسم) لتحديد الاسم أو تصحيح اسم مقروء خطأ، مع منع تكرار اسم في نفس المقارنة.
- **لا ترسية** قبل تسمية كل العروض.
- «طريقة القراءة» تظهر «قراءة مباشرة» بدل اسم المكتبة.
