# دليل التشغيل على الشبكة المحلية

**الفكرة:** نظام واحد يعمل على «الجهاز الرئيسي» فقط (الخادم)، ويفتحه الفريق من المتصفح. المجلد المركزي للملفات يقع على هذا الجهاز نفسه.
هذا يعني: **لا يحتاج أي عضو إلى صلاحية كتابة على المجلد المشترك**، فالخادم هو الذي يكتب، وهذا يُنهي مشاكل الصلاحيات التي ظهرت مع الإكسل.

## 1) تجهيز الجهاز الرئيسي
1. **ثبّت عنوانه**: من إعدادات الراوتر اجعل للجهاز عنوانًا ثابتًا (DHCP Reservation / Static IP). بدونه سيتغير العنوان يومًا فتنقطع الأجهزة الأخرى.
2. **منع السكون**: إعدادات الطاقة → Sleep: Never (وإلا انقطع النظام ليلًا).
3. اجعل نوع الشبكة **Private** (الإعدادات ← الشبكة ← الخصائص).
4. ثبّت بايثون (3.9 فأحدث) إن لم يكن موجودًا، ثم داخل مجلد المشروع:
   ```
   pip install -r requirements.txt
   ```

## 2) المجلد المركزي ومشاركته
1. أنشئ مجلدًا محليًا، مثل `D:\PO_Archive` (لا حاجة لإنشاء فروعه، النظام يبنيها).
2. كلك-يمين ← خصائص ← مشاركة ← مشاركة متقدمة ← «مشاركة هذا المجلد» ← الاسم `PO_Archive`.
3. الأذونات: **المجموعة التي تضم الفريق = قراءة فقط** (Read). حساب مستخدم الخادم = تحكم كامل.
   - القراءة وحدها كافية لتصفح المجلدات من مستكشف الملفات؛ والرفع والاستبدال يتمان من داخل النظام.
4. المسار الذي يراه الفريق: `\\اسم-الجهاز\PO_Archive` (يظهر داخل النظام فوق لوحة المستندات ليُنسخ).

## 3) ملف الإعداد
```
copy config.ini.example config.ini
```
عدّل: `[database] path` (مسار القاعدة، **محلي على هذا الجهاز** أفضل وأسرع من مسار شبكة)، `[storage] archive_root` (المجلد في الخطوة 2)، `share_path`.
ملاحظة: بعد إنشاء `config.ini` لا حاجة لأي `set PO_DB_PATH` كما كنت تفعل.

## 4) تجهيز القاعدة والمستخدمين
```
python migrate.py             ← يحدّث القاعدة (آمن حتى لو سبق تنفيذ السكربتات القديمة يدويًا)
python tools\add_user.py      ← كرّره لكل عضو (3 أعضاء + حسابك)
python tools\setup_check.py   ← يجب أن يظهر «✔ الجهاز جاهز»
python tools\check_storage.py ← يقيس سرعة المجلد ويتأكد من الأسماء العربية والمسارات الطويلة
```

## 5) فتح الجدار الناري (كمسؤول)
كلك-يمين على `deploy\open_firewall.bat` ← **Run as administrator**.
يفتح المنفذ 5000 لـ«الشبكة المحلية فقط» ولأجهزة Tailscale فقط، ولا يفتحه للإنترنت.

## 6) التشغيل
- يدويًا: `deploy\start_server.bat` (تظهر عناوين الدخول في الشاشة).
- تلقائيًا مع تشغيل الجهاز: `deploy\install_autostart.bat` كمسؤول (يعمل بعد دخولك للويندوز بـ30 ثانية، بلا نافذة).
- إيقاف: `deploy\stop_server.bat`.

**للفريق:** افتح المتصفح على `http://عنوان-الجهاز-الرئيسي:5000` وأضفه للمفضلة.

## 7) النسخ الاحتياطي (مهم قبل الاعتماد)
عدّل المسارين داخل `deploy\backup.bat` ثم جدوله يوميًا (Task Scheduler) إلى قرص آخر. ينسخ القاعدة بتاريخ اليوم ويعكس مجلد الأرشيف دون حذف أي شيء في الوجهة.

## إن حدثت مشكلة
| العَرَض | الحل |
|---|---|
| الجهاز الآخر لا يفتح الصفحة | `open_firewall.bat` نُفّذ؟ نوع الشبكة Private؟ العنوان صحيح؟ جرّب `ping عنوان-الخادم` |
| صفحة «حدث خطأ غير متوقع» | افتح `logs\error.log` وأرسل آخر سطور (فيها السبب) |
| بطء | `python tools\uat_report.py` يبيّن أبطأ الصفحات؛ `/health` يعرض أزمنة القاعدة والمجلد |
| الملف لا يُرفع | الصيغ المسموحة PDF/JPG/PNG/Word/Excel والحجم الأقصى 50MB (قابل للتعديل في config.ini) |
