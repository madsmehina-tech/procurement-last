# v26.2

1. **إصلاح صفحة «بيانات الشركة»:** كانت ما تزال تعرض «المحاسب» ولا تحفظ الموقّعَين الجديدين. صارت: مدير العقود والمشتريات · مدير عام المشاريع · مدير الحسابات · المدير المالي · المدير العام + القسم (يظهر تحت اسم الشركة)، وتُحفظ وتُنقل تلقائياً إلى كل أمر صرف جديد. (اختبار يضمن ذلك.)
2. **نسخة أرشيف لكل أمر صرف:** عند الاعتماد تُحفظ نسخة PDF في الأرشيف `أوامر الصرف العامة / السنة / PR-xxxx / PR-xxxx.pdf` وتُفهرس في جدول المستندات، ويظهر رابطها ومسارها أعلى صفحة الأمر. زر «حفظ نسخة في الأرشيف / تحديث» عند الحاجة. فشل إنشاء الـPDF لا يُفشل الاعتماد ولا الدفعة.
3. صلاحية عرض المستند من نوع أمر الصرف مرتبطة بصلاحية «عرض أوامر الصرف».
