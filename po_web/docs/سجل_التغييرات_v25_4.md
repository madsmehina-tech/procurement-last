# التغييرات في النسخة 25.4

1. **رقم «المتبقي» واحد في كل مكان (M-06):** كشف الحساب وأرقام صفحة المقاول وملخّصها العلوي تعطي الآن الرقم نفسه في كل الحالات (دفعة جزئية، مستخلص مرفوض سبق الصرف عليه، مستخلص قديم مصروف، حركات يدوية، تسوية عند الإقفال). المال الذي صُرف على مستخلص مرفوض يُحسب كمصروف فعلاً.
2. **حفظ مستند في الأرشيف بلا فقدان (M-18):** تعليم المستند السابق كـ«غير حالي» وتسجيل الجديد يتمّان معاً. إذا فشل الحفظ، يبقى المستند السابق كما هو ويُحذف الملف الجديد (أو يعود الملف المرفوع إلى مكانه).
3. **أسماء المقاولين والمشاريع الطويلة (M-19):** يُقصَّر اسم الملف تلقائياً ليتّسع المسار (حدّ قاعدة البيانات 255 وحدّ ويندوز 260). إن كان اسم المجلد وحده طويلاً جداً تظهر رسالة واضحة تطلب اختصار الاسم، دون ترك ملف يتيم.
4. **أداة تنظيف بيانات الاختبار:** `python tools\wipe_test_data.py` (عرض فقط) و`--apply` للتنفيذ. تنسخ القاعدة احتياطياً أولاً، وتطلب كتابة اسم ملف القاعدة للتأكيد، وتنقل ملفات الأرشيف إلى `_wiped_<تاريخ>` ولا تحذفها، وتعيد الترقيم من البداية. تُبقي المستخدمين والصلاحيات وبيانات الشركة والقوالب والمشاريع والمواقع والموردين والمقاولين وسجل التدقيق.
