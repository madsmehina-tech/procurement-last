# سجل التغييرات — v24.0 (وحدة العقود: عقود واتفاقيات من قوالب Word)

## ما الجديد
**إنشاء عقد للمقاول / اتفاقية توريد للمورد** من قالب Word: النظام يملأ بيانات الأطراف من سجلاتها، ويبني جداول الأسعار (بالضريبة 15% والمبلغ بالحروف) والدفعات والمواصفات، وينتج **ملف Word قابلًا للتعديل + PDF**، ويحفظهما في أرشيف العقد.

### زرّان في صفحة المقاول
- **«+ إضافة عقد (مؤرشف)»** (الموجود): عقد وُقّع خارج النظام يُرفع للأرشفة.
- **«إنشاء عقد للمقاول»** (الجديد): النظام يولّد العقد. وزر «إنشاء اتفاقية توريد» في صفحة المورد.
الاثنان في **نفس سجل العقود** بعمود «المصدر» (مؤرشف / مولَّد)، والنسخة الموقّعة للعقد المولَّد تُرفع على نفس السجل فيتحول إلى «ساري».

### المعالج (شاشة واحدة بخمسة أقسام)
الطرف والقالب ← المشروع والنطاق والمواصفات ← الأسعار (مقطوعية / بالوحدة، سعر قبل الضريبة أو شامل) ← المدة والدفعات (نماذج جاهزة 40/25/35 ...) ← الشروط (غرامة، ضمان، حقول القالب). «حفظ كمسودة» أو «حفظ وإنشاء الملفات». والناقص يبقى **نقاطًا مظللة بالأصفر**.

### القوالب
- قالب = ملف Word بعلامات `{{...}}` و`[[...]]` (ورق الشركة والتنسيق من الملف نفسه).
- **نسخ للقوالب** (الجديدة هي الحالية، والقديمة محفوظة)، وكل عقد يتذكر نسخته؛ العقد غير الموقّع يأخذ أحدث نسخة عند إعادة الإنشاء، والموقّع يبقى على نسخته.
- **حقول إضافية بلا برمجة:** أي اسم جديد في القالب يسأل عنه المعالج؛ و`{{اسم|خيار 1|خيار 2}}` قائمة اختيار.
- «تجربة القالب» ببيانات تجريبية، و«دليل علامات القوالب» داخل النظام. قالب أساسي لعقد مقاول الباطن مرفق للتجربة.

### السجل المركزي (تاب العقود)
عقود المقاولين والموردين معًا؛ بحث بالمقاول والمورد والمشروع والرقم والنوع والمصدر والحالة والفترة الزمنية.

### بيانات
- بيانات التعاقد في ملف المقاول والمورد (العنوان، الممثل وصفته، الرقم الوطني الموحد، البنك، صاحب الحساب) وبيانات الشركة (الطرف الأول) في **الإعدادات ← بيانات الشركة**: تُكتب مرة واحدة.
- ترقيم تلقائي: `SC-2026-001` (البادئة من القالب).
- الحالات: مسودة ← صادر ← ساري (+ موقوف / منتهي / مفسوخ). **المسودات والصادر غير الموقّع واتفاقيات الموردين لا تدخل أرقام المقاول ولا لوحات الإدارة.**
- سجل لكل عقد (إنشاء، تعديل، مراجعة جديدة، رفع النسخة الموقّعة).

### الأرشيف
`إدارة مقاولي الباطن / <المقاول> / العقود / عقد رقم X / ملفات العقد` و`الموردين / <المورد> / عقود واتفاقيات / عقد رقم X / ملفات العقد`؛ كل مراجعة بملف خاص وتبقى القديمة.

### الصلاحيات
حسب قرارك: بلا نظام اعتماد، والصلاحيات اختيارية من **الإعدادات ← الأدوار**: `contractgen.create` (إنشاء) و`contractgen.templates` (القوالب وبيانات الشركة). المدير يملك كل شيء كما هو الآن.

## المطلوب لتشغيلها
1. `pip install -r requirements.txt` (يضيف `python-docx` و`pywin32`).
2. `python migrate.py` (الترحيل m025، إضافات فقط).
3. تحويل PDF: يلزم Word على الجهاز الماستر + pywin32؛ جرّب `python tools\test_contract_pdf.py`. بدونه يُنشأ Word دائمًا ويُرفع PDF يدويًا.

## تغيّر في سلوك قائم
عقود الموردين والمسودات لا تظهر في أرقام «إجمالي قيمة العقود» وعدد العقود. (العقود القديمة بلا تغيير.)
