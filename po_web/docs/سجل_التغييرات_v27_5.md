# v27.5 — موثوقية التشغيل

1. **تعارض تعديل أمر الشراء:** صفحة التعديل تحمل «رقم نسخة» الأمر وقت فتحها. إن حفظ زميل الأمر قبلك لا يُحفظ تعديلك بصمت: تظهر رسالة تعارض (واسم آخر من عدّل) ورابط لفتح الأمر الحالي، وتبقى بياناتك في الصفحة؛ فإن راجعت وضغطت «حفظ التعديل» مرة ثانية يُحفظ.
2. **سجل التدقيق:** كل عملية POST تُسجَّل الآن **مع نتيجتها**: `نجحت` / `رُفضت` (رفض قاعدة عمل خلف تحويل) / `لم تُحفظ (أُعيد عرض الصفحة)` / `فشلت (HTTP n)`، وكانت تُسجَّل سابقاً كنجاح كلما لم يرجع خطأ. وأُضيفت قيم «قبل ← بعد» لحالة أمر الشراء، وملخص تعديل الأمر، ونتيجة تحويل المقاول.
3. **فحص نوع الملف المرفوع:** يجب أن يطابق محتوى الملف امتداده (PDF/PNG/JPG/DOCX/XLSX/DOC/XLS). برنامج مُعاد تسميته إلى .pdf يُرفض.
4. **ترقيم الصفحات:** قائمة أوامر الشراء والمستخلصات تُعرض 100 سجل في الصفحة مع روابط الصفحات، وتبقى الإجماليات والأعداد محسوبة على القائمة كلها. تصدير Excel كما كان (كل السجلات).
5. **CI وقفل التبعيات:** `.github/workflows/tests.yml` يشغّل الاختبارات وفحص الثغرات على كل رفع؛ `requirements.lock.txt` بالإصدارات التي اختُبرت؛ `requirements-dev.txt` لأدوات الاختبار.
